# 上财 Wiki 贡献规范

这份 Wiki 面向上财学生。贡献路径：找到条目 → 点击「编辑」→ 修改并预览 →「直接发布」。新增内容用「新增条目」，选择所属目录。发布立即生效，无需审核。

## 写什么

- 写同学能用得上的事实、办理步骤、入口、时间和经验。一条内容解决一个问题。
- 政策优先引用学校、学院或负责部门的原始通知，并写明适用年级和核对日期。不要把其他年级的规则当作通用规则。
- 经验可以写，但要注明时间、校区和个人体验；不把感受写成排名或定论。
- 无法确认的信息标「待核实」，缺少内容留「待补充」。不要用猜测填满空目录。
- 不写闲聊、玩笑、传闻、人身评价、广告、私人联系方式或未经同意的个人信息。

## 怎么组织

- 目录按「主题 → 场景 → 事项」组织；已有条目优先补充，避免重复创建。
- 标题用简短名词，如「外卖柜」「补考」。条目内部需要分段时，再使用 Markdown 标题。
- 多个对象用表格，操作步骤用有序列表，补充说明用引用块。
- 井号与标题写在同一行，例如 `## 办理流程`。编辑器也会自动修复从原稿粘贴的分行标题。
- 一次修改尽量围绕一件事。遇到编辑冲突，先对照最新内容合并，再发布。
- 删除过时或重复条目：打开「编辑」→「删除条目」。可以只删当前条目、将子条目移到上一层，也可以连同全部下级条目删除。确认后立即生效，删除前自动保存维护者可恢复的副本。

## 来源格式

```text
适用范围：2026 级本科生 / 国定路校区
来源：[通知标题](https://学校原文链接)
最后核对：YYYY-MM-DD
```

不知道日期就写「待核实」，不要把编辑时间当作信息核对时间。

## 常用格式

```md
**重点文字**
[链接名称](https://example.com)
[[条目ID|站内条目名称]]

1. 第一步
2. 第二步

| 项目 | 说明 |
| --- | --- |
| 办理入口 | 上财门户 |

> [!提示] 这里写补充说明。
> [!待核实] 这里写需要进一步确认的内容。

- [ ] 等待补充来源
```

标题旁的链接按钮可复制条目地址。网页支持表格、列表、引用、代码块、任务清单和站内链接，不执行原始 HTML。

规范参考：[MediaWiki 编辑页面](https://www.mediawiki.org/wiki/Help:Editing_pages/zh)、[格式说明](https://www.mediawiki.org/wiki/Help:Formatting/zh)。本站实际编辑语法为 Markdown。
